# 重要功能模块

按重要性排序。路径均相对 `scripts/instascene/`（入口脚本除外）。

## 1. vlm/pipeline.py — 主编排（核心）

- `process_scene(config, scene_input: SceneRunInput) -> Path`：单场景全流程。从 manifest 解析的路径加载 → pending 物体 → 并发 VLM → 写 JSON。
- `SceneRunInput`：`dataset_id`、`scene_key`、`ResolvedScenePaths`、`id_map_source`、`pair_by`。
- 输出条目：`{id, instance_id, n_views, mode, response}`，落盘到 `outputs/run_*/<dataset_id>/<scene_key>/`。

## 2. vlm/config.py — 配置中枢

- `SceneInputConfig` 只含 `manifest_path`；mask 格式和配对策略从 manifest 元数据读取。
- `scene_output_dir(dataset_id, scene_key)`：输出目录相对 cwd。

## 3. scene/loaders/scene.py — 场景加载统一入口

- `load_scene_from_paths(dataset_id, resolved, id_map_source, pair_by) -> SceneData`：标注链和统计链共用。
- `build_views_from_sam2_json()`：RE10K 的 sam2_json 分支。

## 4. manifest/sample_registry.py — 唯一数据集注册表

- `SAMPLE_JOB_CONFIGS`：6 个数据集（3dovs/lerf/zipnerf/infinigen/re10k/scannetpp_v2），各绑定 discover、`id_map_source`、`pair_by`、默认根路径。
- **新增数据集只改这里 + 一个 discover 函数**。

## 5. manifest/sample.py + io.py — manifest 读写

- `run_sample_job()`：discover → 采样（`random.Random(seed)` 可复现）→ 写 JSON（含 `dataset_id`、`id_map_source`、`pair_by`）。
- `load_scene_paths_manifest()` / `resolve_scene_paths()` / `manifest_*()` 辅助函数。

## 6. scene/discovery/ — 每个数据集一个 discover 函数

- `local.py`：`discover_local_extracted()`，本地 flat 布局。
- `ins_scene_15k.py`：infinigen / re10k / scannetpp_v2。

## 7. vlm/selector.py + preparer.py + client.py

- 选视角、拼图 spec 渲染、OpenAI 兼容 API 调用（与重构前相同）。

## 8. stats/scene_views.py — 场景统计

- `summarize_manifest_scene()`：调用 `load_scene_from_paths()` 后计数；供 `batch_manifest_stats.py` 使用。

## 9. 入口脚本（scripts/）

| 脚本 | 作用 |
|---|---|
| `sample_scenes.py` | 数据层：按 `--dataset` 生成 manifest JSON |
| `vlm_gen_scene_desc.py` | 标注层：`--manifest` 驱动 VLM pipeline |
| `batch_manifest_stats.py` | manifest 批量统计（`--id-map-source auto` / `--pair-by auto`） |
| `ask_vlm_image_audit.py` | VLM 多图可见性探针 |
| `visualize_sam_masks.py` | mask 上色可视化（独立小工具） |

## 10. 数据资产

- `assets/`：物理感知本体 schema。
- `prompts/`：prompt 实验版本。
- `configs/`：view compose spec。
- 本地场景：`3dovs/`、`lerf/`、`zipnerf/`。
