# 心智模型与快速上手

## 一句话理解这个仓库

**这是一个「场景数据仓库 + VLM 实例级物理感知标注 pipeline」**：本地或远端存放预处理好的多视角场景数据（RGB 图像 + 跨视角一致的实例分割 mask），先用 manifest 固定要处理的场景子集，再遍历每个场景里的每个物体实例，挑选该物体可见质量最好的几个视角，把它们渲染成"多面板拼图"发给一个 OpenAI 兼容的 VLM，让模型输出该物体的**物理仿真中间表示**，结果按 run 落盘为 JSON。

## 心智模型：两条线

```
① 数据层:  sample_scenes.py --dataset ...  →  manifest.json（固定场景子集，可复用）
② 标注层:  vlm_gen_scene_desc.py --manifest ...  →  outputs/run_*/<dataset>/<scene_key>/<model>.json

工具线: ask_vlm_image_audit（验证 VLM 真能看到几张图）、visualize_sam_masks（mask 上色可视化）
统计:   batch_manifest_stats.py --manifest ...（跑标注前评估 n_views / n_objects）
```

理解时抓住三个关键抽象：

1. **manifest 是数据层边界**：不同数据集（3dovs/lerf/zipnerf/infinigen/re10k/scannetpp_v2）各自一个 discover 函数，注册在 `manifest/sample_registry.py`；manifest 里写死路径、`id_map_source`、`pair_by`，标注层不再猜目录 layout。
2. **实例 ID 跨视角一致**：mask 里同一个像素值（如 `5`）在一个场景所有视角里指同一个物体。整个 pipeline 以 `(dataset_id, scene_key, object_id)` 为处理单元，`instance_id` 形如 `3dovs_bench_inst005`。
3. **一个 run 一个目录**：每次执行产出 `outputs/run_<时间戳或名字>/<dataset_id>/<scene_key>/<model>.json`，带断点续传、`errors.log`、`debug_inputs/`。

## 快速上手

### 环境

Python ≥3.10，依赖：`numpy opencv-python pillow openai tqdm pycocotools`。运行时需在 `scripts/` 下能 import `instascene` 包（在仓库根目录跑 `python scripts/xxx.py` 即可，或 `PYTHONPATH=scripts`）。

### 第一步：生成 manifest

```bash
# 本地 3dovs，只抽 bench 一个场景（-n 1 固定子集，--seed 可复现）
python scripts/sample_scenes.py --dataset 3dovs -n 1 --seed 0 \
  -o outputs/3dovs_bench_manifest.json

# 远端 re10k（默认根路径在 manifest/roots.py，不在那台机器上要传 --root）
python scripts/sample_scenes.py --dataset re10k -n 100 --seed 0 \
  -o outputs/re10k_manifest.json
```

### 第二步：跑标注

```bash
export VLM_API_KEY=sk-...   # 或 --api-key

python scripts/vlm_gen_scene_desc.py \
  --manifest outputs/3dovs_bench_manifest.json \
  --prompt-file prompts/physics_perception_concise_v2.prompt \
  --view-compose-spec-file configs/view_compose_h2.json \
  --max-views 4 \
  --model-name qwen3.6-27b \
  --api-base-url https://yunwu.ai/v1
```

- 想先小成本验证：加 `--single-object` 或 `--object-id 3`。
- 重复执行同一 `--output-dir` 会断点续传。

### 跑统计（可选）

```bash
python scripts/batch_manifest_stats.py \
  --manifest outputs/re10k_manifest.json \
  --output outputs/re10k_stats.json --print-summary
```

`--id-map-source` 和 `--pair-by` 默认 `auto`，从 manifest 元数据读取。

### 排查 VLM 多图问题

```bash
python scripts/ask_vlm_image_audit.py --images a.jpg b.jpg c.jpg \
  --model-name qwen3.6-27b --api-base-url https://yunwu.ai/v1
```

## 读代码的建议顺序

1. `scripts/sample_scenes.py` + `instascene/manifest/sample_registry.py` — 数据集如何注册、manifest 如何生成
2. `scripts/vlm_gen_scene_desc.py` — 标注 CLI，如何读 manifest 并调 pipeline
3. `scripts/instascene/scene/loaders/scene.py` 的 `load_scene_from_paths()` — 从 manifest 路径加载 `SceneData`
4. `scripts/instascene/vlm/pipeline.py` 的 `process_scene()` — 主编排
5. `selector.py` → `preparer.py` → `client.py` — 选视角、拼图、调 API

## 重要惯例与坑

- **新增数据集**：在 `discovery/` 写一个 discover 函数，在 `sample_registry.py` 加一条 `SampleJobConfig` 即可；VLM pipeline 不用改。
- **partition 只是 manifest 兼容字段**：Infinigen 等有二级目录时用 `partition/scene_name` 作为 `scene_key`；本地 flat 数据集 `scene_key` 就是场景名。
- **prompt 模板是 Python format 字符串**：占位符 `{dataset} {scene} {object_id} ...`；JSON 示例里的大括号要写成 `{{ }}`。
- **mask 尺寸与图像不一致时会自动最近邻 resize**。
- `sample_scenes.py` 的 InsScene-15K 默认根路径写死在 `roots.py`，不在那台机器上要显式传 `--root`。
