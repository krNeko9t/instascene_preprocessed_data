# 心智模型与快速上手

## 一句话理解这个仓库

**这是一个「场景数据仓库 + VLM 实例级物理感知标注 pipeline」**：本地存放若干预处理好的多视角场景数据（RGB 图像 + 跨视角一致的实例分割 mask），核心脚本遍历每个场景里的每个物体实例，挑选该物体可见质量最好的几个视角，把它们渲染成"多面板拼图"发给一个 OpenAI 兼容的 VLM，让模型输出该物体的**物理仿真中间表示**（材质、软硬、轻重、是否可仿真等），结果按 run 落盘为 JSON。

## 心智模型：三条线

```
① 主线（标注）:  场景数据 ──load──▶ 实例ID ──选视角──▶ 拼图渲染 ──▶ VLM ──▶ outputs/run_*/.../<model>.json
② 辅线（选数据）: InsScene-15K 大库 ──sample_scenes──▶ manifest.json ──batch_manifest_stats──▶ 场景/视角/物体统计
③ 工具线:        ask_vlm_image_audit（验证 VLM 真能看到几张图）、visualize_sam_masks（mask 上色可视化）
```

理解时抓住三个关键抽象：

1. **实例 ID 跨视角一致**：mask 里同一个像素值（如 `5`）在一个场景所有视角里指同一个物体。整个 pipeline 以 `(dataset, scene, object_id)` 为处理单元，`instance_id` 形如 `3dovs_bench_inst005`。
2. **id map 三种来源**（`--id-map-source`）：
   - `npy`：`<scene>/id_maps/*.npy`，2D int 数组（本地 3dovs/lerf/zipnerf 默认）
   - `png`：`<scene>/sam/mask/*.png`，8-bit 灰度，像素值即实例 ID
   - `sam2_json`：SAM2 输出的 `auto_masks.json`（COCO RLE），按帧序号与排序后的 RGB 对齐（RE10K 用）
3. **一个 run 一个目录**：每次执行产出 `outputs/run_<时间戳或名字>/<dataset>/<scene>/<model>.json`，带断点续传（已有结果的 object_id 会跳过）、`errors.log`、`debug_inputs/`（实际发给 VLM 的 prompt 和图片）。

## 快速上手

### 环境

Python ≥3.10，依赖：`numpy opencv-python pillow openai tqdm pycocotools`。运行时需在 `scripts/` 下能 import `instascene` 包（在仓库根目录跑 `python scripts/xxx.py` 即可，或 `PYTHONPATH=scripts`）。

### 跑通主线（对一个场景做标注）

```bash
export VLM_API_KEY=sk-...   # 或 --api-key

python scripts/vlm_gen_scene_desc.py \
  --data-root . \
  --dataset 3dovs --scene bench \
  --prompt-file prompts/physics_perception_concise_v2.prompt \
  --view-compose-spec-file configs/view_compose_h2.json \
  --max-views 4 \
  --model-name qwen3.6-27b \
  --api-base-url https://yunwu.ai/v1
```

- 想先小成本验证：加 `--single-object`（只跑第一个待处理物体）或 `--object-id 3`（指定物体）。
- `--dataset all --scene all` 可全量遍历（数据集发现规则：目录下存在 `images/` + `sam/` 的场景才算）。
- 输出在 `outputs/run_<timestamp>/3dovs/bench/qwen3.6-27b.json`；重复执行同一 `--output-dir` 会续传。
- `.vscode/launch.json` 里有现成的调试配置可参考参数组合。

### 跑辅线（从 InsScene-15K 抽样并统计）

```bash
# 1. 抽 100 个 re10k 场景写成 manifest（默认根路径写死在 instascene/manifest/roots.py，指向共享存储）
python scripts/sample_scenes.py --dataset re10k -n 100 --seed 0 -o outputs/re10k_manifest.json

# 2. 统计每个场景的视角数 / 物体数
python scripts/batch_manifest_stats.py --manifest outputs/re10k_manifest.json \
  --id-map-source sam2_json --output outputs/re10k_stats.json --print-summary
```

### 排查 VLM 多图问题

有些代理/模型会悄悄丢图。用探针脚本验证：

```bash
python scripts/ask_vlm_image_audit.py --images a.jpg b.jpg c.jpg \
  --model-name qwen3.6-27b --api-base-url https://yunwu.ai/v1
```

模型会被要求报告"实际看到几张图、每张各是什么"。

## 读代码的建议顺序

1. `scripts/vlm_gen_scene_desc.py` — CLI 入口，看懂所有参数如何汇成 `PipelineConfig`
2. `scripts/instascene/vlm/pipeline.py` 的 `process_scene()` — 主编排，一屏看完整条链
3. `scripts/instascene/scene/loaders/scene.py` 的 `load_scene()` — 三种 id map 来源如何统一成 `SceneData`
4. `scripts/instascene/vlm/selector.py` → `preparer.py` → `client.py` — 选视角、拼图、调 API 三步
5. 需要理解标注语义时看 `prompts/physics_perception_*.prompt` + `assets/ontology_manifest.json`

## 重要惯例与坑

- **prompt 模板是 Python format 字符串**：可用占位符 `{dataset} {scene} {object_id} {n_views} {view_names} {image_mode}`；prompt 文件里的字面大括号要写成 `{{ }}`（见 physics prompt 里 JSON 示例的写法）。
- **视角过滤三阈值**：`min_pixel_count`（绝对像素数）、`min_bbox_area_ratio`（bbox 占整图比例）、`min_pixel_ratio`（mask 像素占 bbox 比例，即"实心程度"）；质量分 = 0.7×(像素/整图) + 0.3×实心度，取 top `max_views`。
- **mask 尺寸与图像不一致时会自动最近邻 resize** 到图像大小（`scene.py:_resize_mask_to_image`）。
- **object_id 0 通常是背景**但 pipeline 不会自动剔除（只剔除负数 ID），0 号也会被送去标注——按需用阈值或 prompt 处理。
- `sample_scenes.py` 的默认数据根写死为 `/mnt/shared-storage-gpfs2/.../InsScene-15K`（`roots.py`），不在那台机器上要显式传 `--root`。
- VLM 请求失败重试 `max_retries` 次（指数退避），单物体最终失败只写 `errors.log` 不中断整场景。
